# Archive: 2026-09-29 — colour aliases (colour system Task 8)

Not imported. These are snapshots taken at `8f030b4f5`, before the pre-colour-system colour names were removed (spec: `docs/superpowers/specs/2026-09-24-color-system-design.md`, stage 6 "Remove aliases"; rulings R-T8a and R-T8h in `.superpowers/sdd/2026-09-24-color-system/progress.md`).

Until Task 8 every old colour name was a CSS alias of its new name, so consumers could move over one stage at a time. Tasks 5–8 moved every consumer (`scripts/rename-color-vars.mjs --check core theme packages` now reports 0), so the aliases had no readers left and were removed. The rename maps stay in the code: `theme/core/src/color-rename-map.json` and `core/web/shared/portfolio-color-names.ts` drive the codemod, the JS input normalisation (old keys passed to the theme API are written under their new names) and the persisted-key migrations.
