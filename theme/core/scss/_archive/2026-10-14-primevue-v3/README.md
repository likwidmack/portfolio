# Archive: 2026-10-14 — PrimeVue v3 Sass theme (`mytheme`)

Not imported. Nothing in this folder is compiled or shipped. Paths below mirror the repo before the change.

PrimeVue runs in styled mode with the Nora preset (`theme/core/src/primevue.ts`), so the PrimeVue v3 Sass theme and the classic Sass path had no reader: `core/web/assets/css/styles.scss` (loaded by both `core/web` and `core/admin`) set `$theme-enable-primevue: false`. The vendored `@tgmc/theme-primevue` workspace package (PrimeVue 3.52.0 Sass themes, MIT licence by PrimeTek, kept here as `theme/primevue/LICENSE.md`) was removed; only our theme and the base it builds on are kept.
