# Archive: 2026-10-06 — responsive layout fixes (KI-8, KI-9)

Not imported. These are full snapshots taken at `379ab4b02`, the base of the responsive layout fixes (PR #256). That PR fixed the bugs the responsive e2e suite found (`core/web-e2e/src/e2e/responsive-components.cy.ts`, the `KNOWN_ISSUES` KI-1 and KI-3 to KI-9). The `.vue` snapshot keeps only its `<style>` block.

| File                                                 | What changed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `core/web/app/pages/gallery/index.scss`              | Full snapshot. **Removed:** the aspect ratio on `.gallery-grid__tile` (`[data-aspect]` → `aspect-ratio`, rows `minmax(0, 1fr) auto`), and the absolute overlay positioning of `.gallery-grid__badge` (top-left) and `.gallery-grid__platform` (bottom-left) over the media. **Now:** the chips sit in a `.gallery-grid__chips` row in the tile meta. The ratio is reserved on `.gallery-grid__media`, strict for photos and video and a floor for text exhibits. The exhibit caption is `.gallery-grid__caption` in the meta (KI-8: the chips covered the caption and code, and a short wide tile squeezed the media). |
| `core/web/app/components/gallery/GalleryExhibit.vue` | `<style>` only. **Removed:** the unconditional overlay caption (`position: absolute; inset: auto 0.65rem 0.65rem; backdrop-filter`). **Now:** the overlay applies only over a photo or video. Over code or viz the caption takes its own grid row. The gallery grid passes `caption-placement="none"` and shows the caption in the tile meta.                                                                                                                                                                                                                                                                          |
| `theme/core/scss/_layout.scss`                       | Full snapshot. **Removed:** the unconditional `html { scroll-behavior: smooth; }`. **Now:** smooth only under `prefers-reduced-motion: no-preference` without `html[data-motion='reduced']`, or with `html[data-motion='playful']`. Scripted scrolls pass `behavior: 'auto'` (it defers to this property), so reduced-motion readers were still scrolled smoothly.                                                                                                                                                                                                                                                     |
