# Public static assets (CDN / Nitro `.output/public`)

| Prefix | Contents                                                 |
| ------ | -------------------------------------------------------- |
| `i/`   | Images (portfolio, tesseract, profile photos)            |
| `v/`   | Video loops and reels                                    |
| `d/`   | PDFs, HTML labs (`d/htm/`), legacy lab scripts (`d/js/`) |

`favicon.ico` stays at the bucket root. URL paths mirror these folders (e.g. `/i/portfolio/social-card.png`).
