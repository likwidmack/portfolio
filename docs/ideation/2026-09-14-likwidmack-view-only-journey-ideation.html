Ideation: LIKWIDMACK view-only journey

Date: 2026-09-14

Topic: likwidmack-view-only-journey

Focus: Reposition the public site from website-as-product to a view-only journey. Chosen home spine: a splash with three doors in this order — Discovery, Process, Exhibition. Proof of work is sorted into those doors, not a fourth. Work is named by medium, question, and artifact — not by employment history.

Mode: repo-grounded

Grounding Context

Public copy lives in Nuxt Content JSON. Primary nav is Work, About, Gallery, Writing, Code, plus Get in touch and Personalize. Work sub-nav adds Docs, AI Lab, and Process. Home still leads with availability, Download CV, and Start a conversation. About is a Digital CV. Gallery is implemented as typed exhibits wrapped in social-feed copy (Shorts/Reels, views, likes). Code is framed as “repos not bio.” The document title suffix is still “Portfolio App.”

STRATEGY.md is product authority: peers view to discover, learn, and be entertained; there is no exchange other than viewing; gallery is an exhibition; do not lead with the website-as-product; work is identified by craft, with employers only as provenance.

Six case studies, an evidence dialog, four sanitized decision cards, and seven code samples already exist as proof. Adjacent prior art: Nicky Case (play/read/watch), Red Blob Games (learn by operating), Lucas Martinic (prototype series), Laurel Schwulst (authored world). Counterexamples: spectacle 3D portfolios and sales-funnel creative sites.

1. Trailhead home

The first screen either inventories you or starts the walk.

Description
Rebuild / as a splash with three doors, in order: Discovery, Process, Exhibition. That is the only fork; each door is then a walk, not another sitemap. When a previous interior page exists, the splash also offers to continue from it. The visitor can skip the splash on the next visit; the splash stays reachable as a view.
Axis
Discovery journey
Basis
direct: STRATEGY.md — “A journey people want to stay on, not a menu of the app.” direct: home.json still leads with availability for principal roles, Download CV, and Start a conversation.
Rationale
If home remains a plaza of credentials, every inner page inherits “pick a destination.” Sequence is how peers feel progression of craft without a résumé map.
Downsides
Returning visitors lose a sitemap-first habit. The first six beats must be chosen and defended. Some peers will hunt for a CV and not find it on beat one.
Confidence
90%
Complexity

2. Herbarium hanging

The typed exhibit already exists; the social costume does not have to.

Description
Keep code | media | viz exhibits. Retire Shorts/Reels language, views, likes, and infinite-feed behavior. Mount each piece as a specimen or alcove: medium, series, what it is a sample of, optional provenance footnote. Finite rooms, a closing piece.
Axis
Exhibition
Basis
direct: STRATEGY.md — “Gallery as an exhibition of work.” direct: gallery.json eyebrow “social feed” and lede “Scan it like Shorts and Reels.”
Rationale
Exhibition is a named track with almost no other use of the word in the repo. Until the metaphor dies, Gallery cannot do the job strategy named.
Downsides
Feed/grid tests and copy churn. Some playful energy of the current gallery is lost on purpose.

3. Quiet frame

Description
Chrome names the room and the position in the walk — not “TMack Portfolio App.” Remove Get in touch from primary nav, demote Docs / AI Lab / Process as peers of the work, and stop billing Personalize like a SaaS panel. Previous / next / index stay. If mail or a PDF exists, it is back-of-house, not a door handle.
Axis
Site chrome
Basis
direct: profile.json titleSuffix “Portfolio App” and siteDescription “web portfolio application.” direct: AppPrimaryNav includes Get in touch and Personalize. direct: STRATEGY.md forbids selling, collaboration, and leading with website-as-product.
Rationale
The tab title is the first sentence peers read. Calling it an App tells them the subject is the software.
Downsides
Analytics currently track contact and résumé events. Quiet chrome makes those metrics rarer by design.
Confidence
86%
Complexity

4. Medium continuum

Description
Replace six equally ranked capability plaques with one walk that changes medium as you move — playback, encoding, spatial gates, product grammar, directed generation, human-gated agents. Not an employer timeline. Provenance may appear in wall text.

5. Operate the proof

Description
Proof is what a peer can run or recover: the player, the helix, the approval gate, a stalled feed as an interface state. Hang the seven code samples on the stories they already declare usedIn. Keep a compact replay of named failure states. Do not lead with fields labeled “proof.”
Axis
Proof of work
Basis
direct: evidence dialog already links sanitized snippets to live surfaces. direct: code.json samples include usedIn. direct: AI Lab and data-visualization case studies already name timeout, reject, and stalled-feed as states.
Rationale
STRATEGY’s problem is that a résumé cannot show how the work feels. Labeled proof fields are a résumé with better CSS.
Downsides
Interactive proof is more to maintain than a caption. Must stay view-only and sanitized.

The Lab can be encountered as how a decision looks from the inside — not billed as a stack tour.
